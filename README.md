ENTER NOW — Prototype v0.1

Purpose:
A deliberately simple Windows laboratory for testing the core Enter Now experience.

Default first experiment:
- Session: 30 minutes
- Random cue interval: 5–15 minutes
- Practice: Third Eye
- Cue: two-tone bell + ENTER NOW
- Cue display: 7 seconds
- Each cue is timestamped in the on-screen log

Requirements:
- Windows
- Python 3.10+ (Python 3.11 recommended)
- No third-party packages required

Run:
    python enter_now.py

Experiment:
Start the session and then do something normal. Do not sit and wait for the cue.
If you notice yourself wondering when it will happen, notice that too.

This is intentionally not the finished product. The goal is to test the experience first.
